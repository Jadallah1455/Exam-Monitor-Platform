# مراقب الامتحانات (Exam Monitor)

إضافة رسمية لنظام مودل (Moodle) — قفل وصول للاختبارات يرصد سلوك الطالب داخل المتصفح
أثناء الامتحان، ويرسل الأحداث إلى منصة كشف الغش الذكية التي تحسب نسبة الغش المحتملة لكل طالب.

## المميزات

- رصد 22+ إشارة سلوكية: نسخ / لصق / لقطة شاشة / إخفاء التبويب / مغادرة الصفحة /
  أدوات المطوّر (F12) / مفاتيح مشبوهة / تغيير الإجابات / انقطاع النت / الخمول ...
- منع اختياري قابل للتفعيل لكل اختبار: منع النسخ / اللصق / النقر الأيمن / الطباعة /
  اختصارات المطوّر (F12 و Ctrl+Shift+I/J/C) — مع بقاء كل محاولة مسجّلة في لوحة التحكم.
- مزامنة تلقائية للدورات والامتحانات والمدرّسين مع منصة الرصد.
- تسجيل تلقائي للمدرّس عند حفظ الامتحان.
- لا حاجة لمعالجة الخادم — كل الرصد يتم داخل متصفح الطالب.

## المتطلبات

- Moodle 3.11 أو أحدث.
- PHP 7.4 أو أحدث.
- موقع منصة "مراقب الامتحانات" منشور (الطرف الخادم).

## التثبيت

### تلقائياً (سطر واحد)

```bash
cd /var/www/moodle/mod/quiz/accessrule
git clone https://github.com/Jadallah1455/Exam-Monitor-Platform.git exammonitor
sudo -u www-data php /var/www/moodle/admin/cli/upgrade.php
```

> المسار القياسي داخل مودل هو `mod/quiz/accessrule/exammonitor` — استبدل فقط جزء
> الجذر (مثال: `/var/www/moodle`) بمسار مودل على خادمك.

### يدوياً (رفع ZIP)

1. حمّل `exammonitor.zip` من قسم Releases.
2. إدارة الموقع ← الإضافات ← تثبيت إضافات ← ارفع الملف.

## الإعداد

1. إدارة الموقع ← الإضافات ← قواعد الوصول للاختبار ← فعّل **Exam monitor**.
2. في **الإعدادات** ضع:
   - `Sync server URL`: عنوان المنصة (مثال: `https://your-platform.com`).
   - `Sync secret`: المفتاح السري نفسه الموجود في `config.local.php` للمنصة.
3. احفظ، ثم فعّل خيار **Enable Exam Monitor** على أي اختبار، واختر من قائمة
   **Optional enforcement** ما تريد منعه فعلياً (النسخ / اللصق / النقر الأيمن /
   الطباعة / اختصارات المطوّر). كل محاولة تبقى مسجّلة في لوحة التحكم حتى لو مُنعت.

## الاستخدام

عند بدء الطالب للامتحان يرصد المتصفح سلوكه، وتظهر النتائج فوراً في لوحة تحكم المنصة
مع إمكانية تخصيص معادلة الغش (نسبة كل محدد من 0 إلى 100%).
